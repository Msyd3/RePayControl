# تعريف المقاييس

الأرقام تعتمد على الأحداث المستقبلة فقط. الأصفار قبل التثبيت تعني عدم وجود بيانات في مركز القياس، ولا تثبت أن المواقع بلا زوار. الفلاتر فترات متحركة: آخر 24 ساعة أو 7/30/90 يومًا. التجميع اليومي بتوقيت الرياض UTC+3.

| آخر استقبال لكل مشروع | أحدث توقيت حدث داخل الفترة | قاعدة القياس |

لا يُدمج visitor بين الأجهزة أو المنتجات، ولا يُساوى بالإنسان أو بالحساب المسجّل. يمكن للمتصفح/مانع الإعلانات/رفض الموافقة حجب التتبّع. المصدر الداخلي لا يقيس طلبات الصور أو كل XHR تلقائيًا، ولا يُعتمد عليه كقياس شامل لكل حركة الخادم.

## مسارات الإصدار الحالي

- الأعمال: page_view → form_start → form_submit → lead_created.
- المحفظة: page_view → otp_requested → otp_verified → checkout_started → payment_succeeded.
- POC: message_received → transfer_requested → checkout_started → payment_succeeded.

يجب توحيد معرف الارتباط بين الواجهة والخادم لعدّ المسار كاملًا. ربط POC المرفق لا يفترض امتلاك جلسة متصفح، ولا يربط واتساب بالمحفظة عبر رقم الهاتف؛ ذلك يحتاج تصميم هوية/ارتباط معتمد. ستبقى مراحله اللاحقة فارغة حتى تضاف أحداثها وربطها الصحيح.

## مقاييس تحتاج خدمات أو بيانات إضافية

الاحتفاظ D1/D7/D30، cohorts، LTV وCAC وROAS، صافي الإيراد والاستردادات والتسوية، إجمالي الحسابات والرصيد، عدد التفعيلات والتوثيق، INP الدقيق باستخدام web-vitals، خرائط الحرارة وإعادة الجلسات، الموقع الجغرافي، فواتير AI وToken usage، قياس التوافر والمراقبة الاصطناعية والتنبيهات. لم تُملأ بتقديرات غير موثوقة. يمكن إضافة وحدات لها بعد تحديد المصادر والهوية والتكاليف المطلوبة.
