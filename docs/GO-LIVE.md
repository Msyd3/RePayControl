## واجهة GitHub Pages

Pages يشغّل الواجهة الثابتة، ولا يشغّل Node أو SQLite. جهّزنا scripts/build-pages.mjs وعملية نشر يدوية عبر Actions تتطلب api_origin لخادم RePayControl الحقيقي. يرفض البناء نشر واجهة تشير إلى عنوان API غير محدد أو إلى Pages نفسه، حتى لا تبدو الخدمة متصلة وهي لا تعمل.

إعداد الخادم عند الفصل:

```text
ADMIN_FRONTEND_ORIGIN=https://control.repay.sa
```

بعد نشر الخادم وتشغيل API، شغّل عملية Publish control.repay.sa frontend بمعامل api_origin الصحيح. الجلسة الموقّعة تعود عبر تسجيل دخول الإدارة وتبقى في sessionStorage، ويقبل الخادم طلبات الإدارة من نطاق الواجهة المحدد فقط. الأسرار وقاعدة البيانات لا تدخل ناتج Pages.

خطة GitHub الحالية تطلب مستودعًا عامًا أو ترقية لتفعيل Pages من هذا المستودع الخاص. لم يُحوَّل الكود إلى عام تلقائيًا.
