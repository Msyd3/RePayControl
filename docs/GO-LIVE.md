## حدود الاستضافة الحالية

GitHub Pages يشغّل الملفات الثابتة فقط. الواجهة المنشورة تعرض بوضوح أن تسجيل الدخول والبيانات ينتظران خادم التطبيق، ولا تتضمن بيانات العملاء أو كلمة المرور أو قاعدة البيانات.
النسخة المحلية تشغّل خادم Node.js وقاعدة SQLite وتسجيل الدخول المحمي. لتفعيل ذلك في النطاق العام، انشر الخادم ثم أعد تشغيل workflow النشر مع api_origin الحقيقي واضبط ADMIN_FRONTEND_ORIGIN=https://control.repay.sa.
لا تستخدم localhost أو عنوانًا تجريبيًا كخادم عام، ولا تنشر المفاتيح أو اللقطات في GitHub.
